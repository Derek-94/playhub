# 멍타리 대전 — 기획 v0

- 게임 ID: `mungtari` (폴더 `games/mungtari/`, 리더보드 ID도 동일)
- 장르: 턴제 포물선 대전 (1:1)
- 상태: 1단계(혼자 하는 버전) 개발 예정

## 한 줄 소개

이웃집 강아지 두 마리가 울타리를 사이에 두고 뼈다귀를 던진다. 바람을 읽고 힘을 조절해서 상대 HP를 먼저 0으로 만들면 승리.

## 캐릭터

| 이름 | 위치 | 생김새 |
|---|---|---|
| 콩이 | 왼쪽 집 (플레이어) | 하얗고 동글동글 |
| 보리 | 오른쪽 집 (상대/봇) | 갈색, 귀가 쫑긋 |

- 직접 그린 오리지널 캐릭터. 맞으면 "깨갱", 이기면 꼬리 흔들기.

## 화면 (가로)

```
 바람 ◀◀◀ 3                               ⏱ 12
 [콩이 HP ████████░░]          [보리 HP ██████░░░░]

   집                    ║                    집
   콩이 ↗ 조준선         ║ ← 울타리           보리
 ▔▔▔▔▔▔ 내 정원 ▔▔▔▔▔▔▔▔║▔▔▔▔▔ 상대 정원 ▔▔▔▔▔▔▔
 [힘 게이지 ▓▓▓▓▓░░░]      [아이템 칸 × 3]
```

## 조작

1. 마우스를 움직이면 조준선 각도가 바뀐다.
2. 꾸욱 누르고 있으면 힘 게이지가 찬다.
3. 손을 떼면 던진다.
4. 아이템은 던지기 전에 아이템 칸을 클릭해서 장착한다.

- 게이지를 끝까지 채우면 너무 세게 던져 맵 밖으로 날아가고, 그 턴은 소멸한다.
- 모바일: 누른 채 끌어서 조준하고, 손을 떼면 발사.

## 규칙 (초안 수치)

| 항목 | 값 |
|---|---|
| HP | 100 |
| 직격 | 25 |
| 머리 명중 (크리티컬) | 35 |
| 스침 (근처 착탄) | 10 |
| 울타리 충돌 | 막혀서 그 자리에 떨어짐 |
| 맵 밖 | 턴 소멸 |
| 턴 제한 | 15초, 넘기면 자동으로 턴 넘김 |
| 바람 | 매 턴 변경. 방향 좌/우, 세기 0~5 |
| 장기전 | 20턴 넘으면 HP 많은 쪽 승리 |

## 바람

- 날아가는 동안 수평 방향으로 계속 밀어낸다. 높이 던질수록 체공 시간이 길어 더 많이 밀린다.
- 낮고 세게 던질지, 높고 약하게 던질지 고르는 게 핵심 재미다.
- 표시는 풍향 깃발 + 화살표 개수 + 숫자로 한다.

## 아이템

시작할 때 3개를 랜덤으로 받고, 한 턴에 하나만 쓴다.

| 아이템 | 효과 | 1단계 포함 |
|---|---|---|
| 더블 뼈다귀 | 같은 궤도로 2개 연속 던지기 | O |
| 왕뼈다귀 | 크고 데미지 1.5배. 무거워서 바람 영향↓, 사거리↓ | O |
| 바람 멈춤 (부채) | 이번 턴 바람 0 | O |
| 킁킁 코 | 이번 턴 예상 궤적 전체(착탄 지점까지)를 점선으로 미리 보기 | O |
| 통통 공 | 착지 후 한 번 튀어 굴러감 | 나중에 |
| 개껌 회복 | 던지는 대신 HP +20 (턴 소모) | 나중에 (밸런스 확인 후) |
| 우산 방어 | 상대의 다음 공격 데미지 절반 | 나중에 (밸런스 확인 후) |

## 개발 단계

| 단계 | 내용 |
|---|---|
| 1 | 혼자 하는 버전: 던지기 물리, HP, 아이템, 봇 상대. 서버 없음 |
| 2 | 서버 모듈 매치 핸들러: 턴·판정·승패를 서버가 처리 |
| 3 | Matchmaker 연결(2명 모이면 시작), 턴 타이머, 이탈 처리 |
| 4 | 초대 코드 방, 승수 랭킹, 다듬기 |

### 1단계 범위

- 나(콩이) vs 봇 보리. 봇은 바람을 계산해서 던지되 오차를 섞는다 (쉬움/보통/어려움 = 오차 크기).
- 물리 계산은 `simulate(각도, 힘, 바람, 아이템) → 궤적 + 결과` 순수 함수로 분리한다. 2단계에서 서버 모듈이 이 파일을 그대로 판정에 쓴다 (Nakama JS 런타임이라 npm 라이브러리 없이 순수 TS로).
- 랜덤(바람, 아이템)은 시드 기반으로 해서 같은 시드면 같은 결과가 나오게 한다.
- 그림은 Canvas 2D로 직접 그린다 (이미지 파일 없이 시작, 나중에 교체 가능).
- 랭킹: 봇을 이기면 점수(남은 HP × 10 + 빠른 승리 보너스) 제출. SDK 연동은 게임이 잘 돌아가는 걸 확인한 뒤에 한다.
- 하지 않는 것: 매칭, 실시간 대전, 초대 코드.

## 멀티플레이 구조 (2단계 이후 참고)

- 백엔드는 기존 Nakama 그대로. `server/modules/src/`에 매치 핸들러 파일을 추가하고 `InitModule`에서 등록한다.
- 클라이언트는 `{ angle, power, item }`만 보내고, 서버가 같은 `simulate`로 판정해서 결과를 둘에게 보낸다.
- 바람·아이템 같은 랜덤은 서버가 정해서 내려준다.
- 상대가 안 오면 30초 뒤 봇 대전으로 전환, 초대 코드 방도 제공.
